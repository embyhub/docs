# 操作指南

从注册到发帖，这一篇讲全。

## 注册账号

本站实行**邀请制**。拿到邀请链接后，填邮箱、用户名、密码即可完成注册，**不需要人工审批**。邀请码有四种获取方式（详见 [signup.openxinsheng.com](https://signup.openxinsheng.com)）：

1. **公司内网**：在华为内网环境下打开注册页，页面自动检测网络并直接发放邀请码；
2. **工作邮箱**：用 `@huawei.com` / `@hisilicon.com` 邮箱发邮件到 hi@openxinsheng.com，标题带"邀请码"三字，系统自动回复邀请链接；
3. **QQ 频道**：在「心声社区」QQ 频道内留言申请；
4. **离职员工**：添加微信 `openxinsheng`，通过之前的工作群验证身份后获取。

几点说明：注册邮箱不限，QQ、Gmail、163 都可以；每个浏览器每天限领 1 次（按浏览器指纹），同一出口 IP 下的多位同事互不影响。

## 发帖

点击右上角的**新建话题**按钮，按三步走：

1. **选版块**：内容发到对的版块才有人看（版块介绍见下）；
2. **写标题和正文**：标题说清事，正文把背景、细节一次讲完；
3. **加标签**：方便检索。需要新建标签，联系 @阿拉丁。

几个习惯：长文分段、图片太大先压一下再传；转载注明来源；私密话题可以走私信。

## 回帖与互动

- 看到好帖点 ❤️，优质回复会被顶上去；
- 回复时引用原帖的关键句，讨论才接得上；
- 想单独聊，点对方头像发私信。

## 社区准则

删帖标准很宽松，只有三条红线：

1. **泄露、讨论公司机密**：未公开的业务、数据、人事、技术细节；
2. **单纯谩骂**：没有事实基础的人身攻击；
3. **危害国家安全、违反法律法规**。

除此之外的观点表达、情绪吐槽、信息分享都不干预。完整版见[论坛准则](https://openxinsheng.com/guidelines)。

在这里**可以**做的事：基于事实吐槽主管和部门、自由建群拉群（可发微信群二维码）、找兴趣搭子、行业交流、项目组队、离职时写篇"惯例"总结职业生涯、搬运外站有价值的内容（注明来源）、聊家属的就业创业。

## 身份验证：小红对号

本站有员工验证系统：**随机工号 + 姓**匹配验证，通过后获得"小红对号"标识；公司内网环境下注册可自动完成验证。

提醒一句：**提供工号相当于实名**，想清楚再验证。另外本站**不核实会员身份**（相亲帖、交易帖里的自我介绍都一样），注意甄别、谨防受骗。

## 常见问题

**这个论坛能一直办下去吗？**

能。站长专门回答过：守住三条底线（守法、守公司信息安全规定、不谩骂）风险可控；服务器加域名一年几百块，成本很低；公司论坛有"日落政策"（半年帖子搜不到、离职后无法访问），而这里日不落、离职后还能用，有真实的生存空间。

**忘记密码怎么办？**

登录页点"忘记密码"，按邮箱指引重置。

**账号、帖子有问题找谁？**

直接发帖反馈，或联系 @阿拉丁。
